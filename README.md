# next-angles-session

Structured review of unresolved gaps and next steps.

## What it does

The skill inspects a completed answer and ranks outstanding issues, research directions, useful artifacts and relevant tools. It deliberately avoids replacing the original task. Read `SKILL.md` for the output contract and limits.

## Repository

- `SKILL.md`: usage and behavior

Source files are in `scripts/`, `references/`, `agents/` or `static/` where applicable.

## Notes

Commands that use external services require your own authenticated account. Review generated outputs before sharing them.
