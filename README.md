# next-angles-session

A structured audit of unresolved gaps after an answer is complete.

## What it does

- Ranks unresolved issues by practical priority
- Separates further research from artifacts to create
- Recommends tools only when tied to the current result
- Limits each section to five concrete items

## Quick start

Read `SKILL.md`, then apply it to a conversation with a finished result. Return only sections that contain real follow-up work.

## Browse the repository

- `SKILL.md` — workflow specification

## Compatibility

Prompt/skill file; no code or external service required by default.

## Quality checks

The output contract is explicit in `SKILL.md`; results depend on the quality of the completed answer under review.

## Security and privacy

Inspect source files and your own input data before running or publishing outputs. Do not commit credentials, browser cookies, client documents or generated work directories.

## Limits

Do not use it before the original task has produced a concrete result.
